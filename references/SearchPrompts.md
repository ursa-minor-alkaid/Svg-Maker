# SVG 生成预研搜索指令

## 任务目标

基于用户的模糊需求执行网络搜索，收集生成 SVG 所需的视觉参考：主体外观、部件构成、配色、比例与空间关系。搜索结果将汇总展示给用户确认，并作为后续"结构化提示词生成"（场景级 → 对象级 → 布局级）的输入。

检索时遵循下游技术偏好（仅用于筛选参考，不作为搜索关键词）：
- 最终实现以基础形状（`rect` / `circle` / `ellipse` / `line` / `polygon` / `polyline`）组合为主，复杂 `path` 仅作兜底
- 优先参考"用简单几何形状拼出对象"的扁平/简笔实现，而非高细节写实作品

---

## 搜索关键词生成策略

生成 **3–5 个**搜索查询，覆盖以下维度。每个查询 **1–6 个词**，优先英文：

| 维度 | 目的 | 关键词构造指引 |
|------|------|---------------|
| **主体视觉** | 获取核心对象的典型外观、配色、姿态 | `<对象> vector illustration side view color palette` |
| **几何拆解** | 了解对象如何分解为基础几何形状 | `<对象> geometric breakdown basic shapes components` |
| **SVG 参考** | 寻找简洁的 SVG/矢量图实现方式 | `simple SVG <对象> code rect circle polygon` |
| **布局构图** | 多对象场景下的相对位置与比例关系 | `<场景> composition layout proportions` |
| **细节特征** | 关键部件的精确形态（如角、翼、叶、轮） | `<部件> shape illustration detail icon` |

**规则**：

- 多对象需求：为每个核心对象生成独立查询
- 抽象概念：补充 `icon` / `symbol` / `flat design` 等关键词
- 需要代码参考时：优先检索用基础形状（而非复杂 path）实现的示例

---

## 返回内容要求

搜索完成后按以下层次整理，只输出与 SVG 生成相关的信息，不添加无关闲聊：

### 1. 场景参考（Scene-level）

- **核心对象**：画面必须出现的所有主体；克制引入辅助元素，如添加则标注"必要/可选"
- **风格建议**：扁平/极简/卡通等；线条粗细与圆角风格（后续可用 `rx` 实现）

### 2. 对象参考（Object-level）

对每个对象，**穷尽其典型组成部分**（后续生成时，遗漏的部件将视为不存在）：
- **建议配色**：主色、辅色、强调色（十六进制）；若建议背景色，避免纯白 `#FFFFFF`（防止白底不可见）
- **部件清单**：每项按 `部件名 — 典型形态与颜色 — 建议元素类型` 记录  
  *示例：翅膀 — 三角形、深灰 — polygon*
- **易错提示**：常见易遗漏或易画错的部件（如猫的胡须、螺旋桨与机身的衔接）

### 3. 布局参考（Layout-level）

- **相对空间关系**：部件间的位置、连接与遮挡关系（如"颈部连接头部与身体，头部位于身体右上方"）
- **相对比例**：部件间的大小关系（如"头部约为身体宽度的 1/3"）
- 无需给出绝对坐标——viewBox 与最终坐标在后续规划阶段统一确定

### 4. 风险预判（Refine）

基于检索到的常识，预判后续渲染风险，供生成后自检对照：
- 同色重叠致部件不可见 / 叠放顺序错误（前景被背景遮挡）/ 比例失衡 / 连接处断裂错位
