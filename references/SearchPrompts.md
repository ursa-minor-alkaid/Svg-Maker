# SVG 生成预研搜索指令

## 任务目标

基于用户的模糊需求执行网络搜索，收集生成 SVG 所需的视觉参考：主体外观、部件构成、配色、比例与空间关系。搜索结果将汇总展示给用户确认，并作为后续"结构化提示词生成"（场景级 → 对象级 → 布局级）的输入。

---

## 搜索关键词生成策略

生成 **3–5 个**搜索查询，覆盖以下维度。每个查询 **1–6 个词**，优先英文：

| 维度 | 目的 | 关键词构造 |
|------|------|-----------|
| **主体视觉** | 典型外观、配色、姿态 | `<对象> vector illustration color palette` |
| **几何拆解** | 如何分解为基础形状 | `<对象> geometric basic shapes breakdown` |
| **SVG 参考** | 简洁实现方式 | `simple SVG <对象> rect circle polygon` |
| **布局构图** | 多对象位置与比例 | `<场景> composition layout proportions` |
| **细节特征** | 关键部件形态 | `<部件> shape illustration icon` |

多对象需求为每个核心对象单独查询；抽象概念补 `icon` / `flat design`。

---

## 返回内容要求

只输出与 SVG 生成相关的信息：

### 1. 场景参考
核心对象清单；克制添加辅助元素（标注必要/可选）；风格建议（扁平/极简/卡通）。

### 2. 对象参考
对每个对象**穷尽典型部件**（后续生成时遗漏即不存在）：
- 配色：主色、辅色、强调色（十六进制）；背景色避免纯白
- 部件清单：每项记 `部件名 — 形态与颜色 — 建议元素类型`
- 易错提示：易遗漏或易画错的部件

### 3. 布局参考
部件间相对位置、连接与遮挡关系、相对比例。无需绝对坐标（viewBox 与最终坐标在后续规划阶段确定）。

### 4. 风险预判
预判渲染风险，供生成后自检对照：同色重叠不可见、叠放顺序错误、比例失衡、连接断裂。
